# LightOps CRM

LightOps is a concise CRM scaffold for lighting installation and seasonal lighting businesses.

Quick summary
- Estimate builder, rate card, and profit check prototype.
- Static, mobile-friendly prototype suitable for local testing.

Quick start
- Open index.html in your browser, or serve locally:
  python3 -m http.server 8000
  Visit: http://localhost:8000

Structure
- index.html — prototype UI
- README.md, LICENSE.md, CONTRIBUTING.md, SECURITY.md, CHANGELOG.md
- .env.example — local placeholders
